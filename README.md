# QUICKDROP

اپ اندرویدی انتقال فایل در شبکه محلی، بر پایه پروژه متن‌باز LocalSend.

## وضعیت فعلی
این مخزن پیکربندی ساخت و شخصی‌سازی QUICKDROP را نگه می‌دارد. کد اصلی برنامه در زمان ساخت از مخزن رسمی LocalSend دریافت می‌شود و شناسه اندروید و نام نمایشی به QUICKDROP تغییر می‌کند.

## ساخت APK
1. وارد زبانه **Actions** در GitHub شوید.
2. گردش‌کار **Build QUICKDROP APK** را انتخاب کنید.
3. روی **Run workflow** بزنید.
4. پس از پایان موفق، در بخش **Artifacts** فایل‌های APK را دریافت کنید.

برای بیشتر گوشی‌های جدید اندرویدی، فایل `app-arm64-v8a-release.apk` مناسب است.

## قابلیت‌های پایه
QUICKDROP از قابلیت‌های هسته LocalSend استفاده می‌کند: کشف دستگاه‌ها در شبکه محلی، ارسال و دریافت فایل، انتقال بدون اینترنت، و اشتراک‌گذاری در شبکه محلی.

## مجوز و انتساب
این پروژه بر پایه [LocalSend](https://github.com/localsend/localsend) است که تحت مجوز Apache License 2.0 منتشر شده است. مجوز و اعلان‌های حقوقی منبع اصلی باید همراه نسخه‌های مشتق‌شده حفظ شوند. QUICKDROP نام و برند مستقل این نسخه است و وابستگی آن به پروژه اصلی در اینجا اعلام شده است.
